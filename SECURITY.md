# Security Policy

## Supported Versions

Only the latest release receives security fixes. Sub2API Monitor is tested against current Sub2API API contracts and recommends Sub2API `v0.1.183` or newer.

## Reporting a Vulnerability

Do not open a public issue containing credentials, server addresses, exploit details, or personal data. Use GitHub's **Report a vulnerability** flow in the repository Security tab so the report remains private.

Include the app version, macOS version, Sub2API version, authentication mode, and the smallest reproducible example. Remove all tokens, ordinary API keys, administrator API keys, passwords, cookies, and private hostnames from logs or screenshots. Administrator API keys grant full global privileges and must never be included in a public report.
